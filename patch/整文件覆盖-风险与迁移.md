## 四、跨平台支持（Windows PowerShell + Linux/macOS Node.js）

除原有的 `apply-core-patch.ps1` 外，v2.2.9 新增了纯 Node.js 实现的 **`核心补丁/apply-core-patch.mjs`**：

```bash
# 演练模式（只看会改哪些行，不落盘）
node 核心补丁/apply-core-patch.mjs --app-dir "/opt/QQ-Agent/resources/app" --dry-run

# 正式打补丁（自动备份到目标目录 _core_patch_backup_<时间戳>）
node 核心补丁/apply-core-patch.mjs --app-dir "/opt/QQ-Agent/resources/app"
```
