# 矩阵庭院 · 安装说明

> 给 **QQ Agent** 用的「小鲸鱼养成」技能。
> 群里/私聊各养一只鲸鱼，它会自己出门旅行、按计划寄回明信片、带特产、解锁称号。
>
> **版本**：`travel-whale v1.9.1`
> **测试环境**：QQ Agent v0.4.2（Electron / Node ≥ 20 / ESM）

---

## 二、前置要求

| 项 | 要求 |
|---|---|
| QQ Agent | v0.4.x（需要支持技能 + 后台 ticker） |
| Node | ≥ 20（ESM） |
| **核心补丁** | ⚠️ **必须打**，否则技能启动不了后台推进 |

### 为什么必须打核心补丁

这个技能和普通技能不一样 —— **它要在后台自己跑**（每 60 秒推进所有鲸鱼的旅程）。
但原版核心**没有把服务（sender / store / emit…）暴露给技能**，技能拿不到发送队列，
ticker 起来了也发不出消息。

补丁一共改 3 个文件，细节见 **`CORE-PATCH.md`**：

```
src/skills/manager.js    给 SkillManager 加 setServices() / services / onServices()
src/plugin-loader.js     createSkillApi 的返回值加 services() / onServices()
src/app.js               服务构造完之后调一次 skillManager.setServices({...})
```

> 补丁**完全向后兼容**：原有技能不受影响，不打补丁只是本技能发不出后台消息。

## 三、安装步骤

### 1. 放技能目录

把整个 `travel-whale/` 拷到：

```
<QQ Agent 安装目录>/resources/app/skills/travel-whale/
```

### 2. 打核心补丁

照着 `CORE-PATCH.md` 改那 3 个文件（每个改动都给了**精确的锚点和完整代码**）。

### 3. 重启应用

```
⚠️ 一定要重启，不能只热重载。
   本技能有多个子模块（state/trip/postcard…），
   而热重载**只会重新 import 入口文件**，子模块会一直用 ESM 缓存里的旧版 ——
   新旧搭配会直接报错，而且加载失败是**静默**的（只在 /api/skills 的 lastError 里能看到）。
```

### 4. 启用技能

控制台 →「技能」页 → 找到「矩阵庭院」→ 开启。

### 5. 开养

在群里或私聊说一句：

```
在这养一只鲸鱼
```

会收到见面礼：**200 亿 TOKEN + 1 份中份大白饭**（够出门一趟）。

## 四、必须配的东西

在控制台 →「技能」→「矩阵庭院」里配：

| 配置项 | 说明 | 不填会怎样 |
|---|---|---|
| **whitelist** | 允许养鲸鱼的地方，逗号分隔的群号 / QQ号 | **谁都养不了** |
| **baiduApiKey** | 百度千帆 API Key（可选） | 搜索降级到 Bing（效果差一些，但能用） |
| **testQq** | 「矩阵庭院快速测试」只对谁开放 | 快速测试**对所有人关闭**（推荐留空） |

> 包里**没有任何本地配置**：白名单、API Key、群号、QQ号全部已清空，QQ千帆有免费额度，可以免费使用
> 你需要自己填。真实配置存在你的 `data/config.json`，不在技能目录里。

### 推荐起步配置

```yaml
whaleName: 小鲸鱼          # 它叫什么
whitelist: <你的群号>       # 比如 123456789
baiduApiKey: <你的 Key>     # 可选
testQq: ""                  # 快速测试保持关闭
```

## 五、怎么验证装好了

### ① 技能加载成功

```bash
curl -s http://127.0.0.1:3210/api/skills
```

返回里找 `travel-whale`，确认：

```
version   = "1.9.1"
lastError = ""          ← 必须为空
tools     = 11 个
```

### ② 后台推进起来了

日志里应该有：

```
[travel-whale] 后台推进已启动：每 60 秒一次
```

### ③ 走一遍完整流程

```
群友：在这养一只鲸鱼
      → 🐋 好嘞，从今天起这只小鲸鱼就养在咱们这儿了。+ 200 亿 TOKEN + 1 份中份大白饭

群友：收一下草              → 收 TOKEN
群友：看看商店              → 商店面板
群友：买一份中份大白饭       → 扣 50 亿 TOKEN
群友：让它去旅行            → 🐋 我出门啦 —— 这趟去 XX·XX
      （等几小时）           → 明信片陆续寄回
```

### ④ 控制台看板

控制台应出现「**鲸鱼**」页签，显示每只鲸鱼的位置、资源、明信片计划。

## 六、卸载

1. 删掉 `resources/app/skills/travel-whale/` 整个目录
2. 删掉 `data/skills/travel-whale/`（存档、图片、配额）
3. 核心补丁可以保留（向后兼容，不影响其他技能），也可以照 `CORE-PATCH.md` 的回滚方式撤掉

## 八、这个包里**没有**什么

为保护隐私，打包时已剔除：

- ❌ 白名单（群号 / QQ号）
- ❌ 任何 API Key
- ❌ 测试 QQ 号
- ❌ 鲸鱼存档（`chats/`）、明信片图片（`photos/`）、特产图（`souvenirs/`）
- ❌ 搜索配额记录（`search-quota.json`）
- ❌ 生成的说明图（`help/*.png`，首次用到时会自动重新生成）
