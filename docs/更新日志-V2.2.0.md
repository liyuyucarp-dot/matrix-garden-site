## 一、`sleep-mood` 精简重构 → 内部版本 2.0.1

### 问题

旧版 1.3.1 同时维护 **11 个互相喂数的碎数值**：情绪五维、疲劳五段、愤怒三通道、吃醋、抑郁、满足、
压力池 A/B/C、生命值、好感联动的 35 项概率骰子、冷落惩罚、吵架加速……

后果是三条：

1. **数值自己长腿**：日常在线时长和发言条数都在扣疲劳，聊一天她就"累垮"，和旅途事件没有因果关系；
2. **面板与真实体验脱节**：1200 行的设置里，一半参数互相影响，改一个看不出变化；
3. **黑箱**：她"为什么生气"，日志里只有一个 `angry: 37`，没有原因。

### 做法

| 旧 | 新 |
|---|---|
| 11 维碎数值 | **两条轴**：元气（0~100）+ 具身情境心境（最多 2 个活跃 Tag） |
| 心情是一堆分数 | 心境是**带因果的事件余韵**（`tag` + `why` + 过期时间），例如「被主人顺毛的甜意（因为主人温声互动）」 |
| 日常自然掉疲劳 | **清醒时元气恒定**，只有旅途战斗/奇遇、吃特产、庭院慢生活、睡眠/泡澡才动它 |
| 独立室内作息表 | **单时钟**：她在干什么 100% 由旅行鲸鱼的在途 / 庭院状态接管 |
| 生命值 + 零血失忆 + 归零清库 | 删除（连带 5 个工具） |
| 好感联动 35 项骰子 | 删除（好感仍由 favor-core 自己维护） |
| 疲劳连锁 A/B/C、低血、吵架加速、抑郁、冷落 | 删除 |

保留并加固的：命令睡眠 / 自然睡眠 / 被吵醒概率 / 陪闹 / 刷手机分心闸 / 洗澡 / 自述状态账本 / 旅途瞬间记录。

### 怎么验

在临时数据目录上跑真实引擎（不碰线上数据），实测：

- `mood.json` 迁移：旧 `fatigue.value=1` → 新 `vitality=99`，`fatigue` 仍同步写成 1，`moodSeededAt` 等旧键**一个不丢**，`scale` 更新为 `v4-travel`；
- 旅行事件光标与旧版共用同一文件，**已对平 → 不会重放历史事件**把心境刷一遍；
- 当前存档里读到「在途：普罗斯佩罗星系」，说明单时钟接得上；
- `self-state.json` 四种形态都试过：旧嵌套 sleeping / 旧嵌套 awake / "顶层+self 并存"脏文件 / 空文件 —— 均正确。

### 代价（要知道的）

- **`satisfaction` / `mood` 变成基线常量**（65 起算，随 Tag 加减），不再是长期累积值。面板上那两根条会显得"平稳"。
- **五维 `moods` 的 level 也变成投影值**（`happy` 基线 55、`excited` 20），只用于下游读字段，不再代表真实强度。
- **删掉的功能就是没了**：生命值低血旁白、归零清记忆、好感驱动的情绪波动。想要回来只能装回 1.x。
- 旧的 118 个设置键仍留在 `config.json` 里（不会被读，也不会被删），面板上只显示新的 40 项。

## 二、`autobiography` 改为「睡前沉淀进知识库」→ 内部版本 0.2.1

### 问题（四条，都是实测出来的）

1. **固定 23:30 触发**：那天 23:30 宿主没开着（关机/重启/夜里没挂机），当天素材**永久丢失**，没有补采。
2. **空素材也调模型**：`collectToday()` 返回 0 条时仍然问模型，模型只能凭空编 ——
   实际存档里那条「我游过十月末的海，暮色把浪染成铁灰」就是这么来的（`facts: []`）。
3. **沉淀等于没有沉淀**：只写自己的 `data\autobiography\nodes.json`，**不进宿主长期记忆**
   （`data\memory-v3\` 的唯一写入口是 `memory.write-note`，本插件从没调过），也没人订阅它的能力。
   所以它的全部作用就是"每天往提示词里塞一段"。
4. **每天注入一段变长文本**：虽然带 `volatile` 声明沉到尾部，但仍是每轮都付的 token，且每天内容都在变。

### 做法

| 改什么 | 怎么改 |
|---|---|
| 触发时机 | 删掉 23:30 定时器 → 每 60 秒观察一次睡眠状态。**命令睡眠（`/睡觉`）随时算**；**自然睡眠只在夜里算**（默认 21:00–06:00，可配）。午后小憩不算，也不占当天机会 |
| 沉淀去向 | 巩固完 → 软依赖 `knowledge.write` 写进 `data\knowledge-base\learned\她的回忆.md`，按天分小节。**可检索、可编辑、可被 `kb_search` 想起来** |
| 空素材 | 直接跳过：记一行日志，不落节点、不调模型、不写库 |
| 提示词 | **删掉 `promptSections`**，不再注入。回忆靠知识库检索 |
| 幂等 | `nodes.json` 按日期去重 + 内存标记双保险；同一天重复 tick 不再写第二条 |
| 顺带修 | `isToday()` 补基准时间参数（原来恒定比 `Date.now()`，跨零点会把昨天素材算进今天） |

**睡眠状态怎么判**（这块最容易踩坑）：`/睡觉` 只存在于 `sleep-mood` 的内存变量里，**不写 self-state 文件**，
光看文件永远发现不了。所以：

1. 先读 `ui\mood-dashboard.json`（`sleep-mood` 每 60 秒发布 `sleep.{sleeping,kind}`，这里能看到 `kind:'command'`），
   要求 `publishedAt` 在 10 分钟内；
2. 读不到/过期，回退 `data\self-state.json`（自然睡眠，新旧两种结构都认）。

### 怎么验

假宿主目录 + 数据副本，10 个用例全过：

```
自然睡眠 @ 14:30（午后小憩）   跳过      自然睡眠 @ 21:30   沉淀
自然睡眠 @ 20:30（未入夜）     跳过      自然睡眠 @ 23:40   沉淀
自然睡眠 @ 次日 03:10（跨零点） 沉淀      自然睡眠 @ 07:30   跳过
命令睡眠 @ 14:30              沉淀      命令睡眠 @ 07:30   沉淀
醒着 @ 23:40                  不动      无 dashboard → self-state 兜底 @22:10 沉淀
```

另外用**真实的 knowledge-base 代码**跑了一遍端到端：新建 `learned\她的回忆.md`（索引 1 段）→
不同内容追加 `## 日期` 小节 → 同内容被自带防重拦下 → `search('煮茶 小月亮')` 命中 2 段。

### 代价

- **不再"白天想起来"**：删掉注入后，只有当知识库**检索命中**时她才会想起旧事
  （知识库是 `index` 模式：目录常驻 + 命中给详情）。若你的知识库 `injectMode=off`，那就只剩她主动 `kb_search`。
- **一天最多一条**：半夜里她如果分几段睡，也只沉淀一次。
- **靠 sleep-mood 的睡眠状态**：`sleep-mood` 关掉/没装时，只能靠 `self-state.json` 认自然睡眠，**命令睡眠认不出来**。
- **素材源依赖路径**：庭院活动读 `travel-whale` 存档、B站读 `plugin-data\bili-whale`、好感读 `memory\people`——
  某个组件没装就少一块，不会报错。
- 旧的 `nodes.json` 里那条 10-24 的空素材记录还在（不影响任何逻辑，想清掉直接删 `data\autobiography\` 即可）。

## 五、升级注意（重要）

### ① 替换 `sleep-mood` 必须**先停宿主**

`plugin-loader` 只给插件**入口**加 `?t=` 时间戳，`lib\*.js` 的相对 import 仍走 ESM 缓存。
热重扫会出现"`index.js` 是 v2、`lib` 还是 v1"的混合态（v2 调 v1 里不存在的函数会直接抛错）。
⇒ **关掉 QQ Agent → 覆盖 → 再启动**。`autobiography` 是单文件，热重扫即可，但一起重启最省事。

### ② 旧 1.x 的残留文件要清

包里的 `sleep-mood` 只有 11 个文件。如果你原本是 1.x，目录里还会有
`lib\hp-system.js`、`lib\favor-link.js` 和一堆 `*.bak-*` —— 它们不会被覆盖，也不会被引用，
但会让人（和未来的你）看错。建议**移走**（别直接删，留着能回滚）：

```
QQ Agent\resources\app\plugins\sleep-mood\lib\hp-system.js
QQ Agent\resources\app\plugins\sleep-mood\lib\favor-link.js
QQ Agent\resources\app\plugins\sleep-mood\*.bak-*
QQ Agent\resources\app\plugins\sleep-mood\lib\*.bak-*
```

### ③ 备份

覆盖前把整个 `plugins\sleep-mood\` 目录复制一份（连同 `data\mood.json`、`data\self-state.json`）。
回滚 = 停宿主 → 覆盖回去 → 启动；**数据不用回滚**（v2 只往 `mood.json` 追加 `vitality`/`activeTags` 并改 `scale`）。

### ④ 启动日志对照

```
[skill:sleep-mood] 睡眠·元气·旅行心境系统 v2.0 已启用：元气 xx/100 · 活跃心境 N 个
[skill:autobiography] 自传体记忆已加载（睡前触发：命令睡眠随时 / 自然睡眠限 21:00–6:00 · 每 60s 观察一次 · 沉淀进知识库「她的回忆」 · LLM=开）
```

第一条出现 v2.0 字样 = `sleep-mood` 换成功了；第二条出现"睡前触发" = `autobiography` 换成功了。
