## 三、装完必须做的三件事

### ① 填群号（不填等于没装）

包里所有跟"哪个群"有关的配置我**都清空了**（那是原作者的私人配置，不该带给你）。
装完到设置页填：

| 组件 | 设置项 | 填什么 |
|---|---|---|
| 矩阵庭院 | `homeChatKey` | `group:你的群号` ← **最要紧**，不填她不会自动出门 |
| 矩阵庭院 | `cardTargets` | 明信片投递到哪（群号或 `private:QQ号`，逗号分隔） |
| sleep-mood | `travelGroups` | 哪些群同步旅行状态 |

### ② 打开「内心层」类开关

`mind-wish`（念想）、`think-gate`（思考分级）默认是开的，但都在插件设置里有一个总开关 ——
装完去确认一下，有些版本的 UI 会把新插件显示成关闭状态。
v2 的 `courtyard-doctor` / `courtyard-map` 也一样，显示关闭就手动开。

### ③ 重启程序

插件是热加载的，但**技能不是**，而且核心补丁必须重启。所以：【装完一律重启一次】。

## 五、两个依赖要说清楚

### ① `bili-whale` 是**软依赖**

- `qqzone` 的日记有 **1/4 篇幅**写"B站刷到了什么"
- `mind-wish` 的三路来源里有一路是 B站见闻

**没有 bili-whale，这两处会静默降级**（不报错、不崩，只是那部分内容为空）。包里有它，但它是**独立插件**，
需要自己在设置里配好（账号 / 看视频的时间段等），不配就只在"有记录"时才有素材。

### ② `mind-wish` 会**读**别的插件的数据

它读 `sleep-mood` 的 `mood.json`、`sleep-mood-moments.json`，读 `bili-whale` 的 `storage.json`。
**只读，不写** —— 所以那些插件挂了不影响念想，念想挂了也不影响她们。

### ③ `courtyard-map` / `courtyard-doctor` 只读矩阵庭院

面板和体检都**只读** travel-whale 的存档与数据表（本包已带），不写、不拦截、不影响出题与旅行。
它们 import `fs`/`path`，遇到宿主「高危能力闸」拦截时，把 `courtyard-doctor`、`courtyard-map`
追加进 `trustedPlugins`（同 mind-wish 的处理，见 安装说明.md 第四节）。
