## 一、这是什么

给 QQ Agent 加的一整套「她自己的生活」：会旅行、会写空间日记、有心情与身体状态、
会自己惦记事情、有可视化面板。全部组件在 `components/`，两套宿主补丁在 `patch/` 与 `adapter-04/`。

## 三、宿主有两类，补丁别打错

| 宿主 | 形态 | 用哪套补丁 |
|---|---|---|
| QQ Agent **0.4.8.x**（安装版） | `<安装目录>\resources\app\` 下是 `src/ skills/ plugins/` | `patch/`（18 项） |
| **官方 0.4 preview**（源码树） | 根目录直接就是 `src/ skills/ plugins/ ui/` | `adapter-04/`（19 项） |

> 两套**不能混用**。`tools/install.mjs` 与 `install.ps1` 都会自动识别。

## 四、三条命令（开发者）

```bash
node tools/build-release.mjs --no-zip   # 跑七道闸（组件清单/语法/加载×2/core自检/快照/脱敏/面板）
node tools/build-release.mjs            # 跑闸 + 出开发者包 dist/matrix-garden-vX.zip
node tools/build-dist.mjs               # 出外发包 dist/矩阵庭院-外发版-vX.zip（双击即装）
```

任一闸失败**不产包**。闸 4（快照探针）与闸 3c（qzone-core 自检）是踩过坑之后加的，别关。

## 五、发版（人只做三件事）

1. 改 `components.json` 的 `version`（组件版本在各自 manifest 里）；
2. 在 `docs/更新日志-全部.md` **顶部**加一条（一句话 + 要点小节）；
3. `git tag vX.Y.Z && git push --tags` —— CI 跑闸并挂 Release。

## 六、几条硬约束（踩过坑才写下来的）

- **打包只能"锚点打补丁"**：包内是脱敏版、现役宿主含真名，绝不允许整文件覆盖回去。
- **验证要针对发布物**：v2.2.7 的 `portraitExists` 就是"在工作副本上验、在发布物上错位"漏出去的。
- **改面板资源必须带 `?v=`**：否则宿主缓存，改了看不到。
- **存档不搬家**：`data/skills/<id>/` 是用户资产，任何重构都不动它。
- **角色图不随仓库分发**：来源混杂、部分无授权，只留 `assets-optional/refs.manifest.json`（sha256 清单）。

## 七、v3.0.0 变了什么（最重要的一条）

`qqzone` 技能已**并入** `qzone`：组件 16 → 15、技能 5 → 4。
升级已装过旧版的机器时**必须删掉 `skills/qqzone`**，否则两套日记工具并存。
详见 `更新日志-全部.md` 第一节。
