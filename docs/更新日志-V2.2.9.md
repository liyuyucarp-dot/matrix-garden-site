## 一、【高】修复 `think-gate` 思考分级在真实运行中的空转失效（1.0.0 → 1.1.0）

### 根因

`plugins/think-gate/lib/decide.js` 原版的 `pickLatestText(messages)` 直接取最后一条 `user` 消息的**最后一行**（`lines[lines.length - 1]`），并在 `decide()` 中规定只要含任何数字（`/[0-9０-９]/`）就必须思考（`skip: false`）。

但在真实运行环境中：
1. `src/prompt.js` 的 `buildUserPrompt()` 拼装顺序是：`【过去状态】 → 【本次唤醒】 → 【此刻状态】 → 【当前时间】2026-10-27 16:20`，且多个插件（`sleep-mood` / `favor-core` / `life-system` / `knowledge-base`）会在 `before-llm-messages` 钩子中继续往最后一条 `user` 消息末尾追加状态段；
2. `mind-wish` 插件会往 `messages` 数组末尾 `push` 一条独立的 `{ role: 'user', content: '【心里偶尔浮起来的小事】…' }`；
3. `buildTriggerBlock()` 会给每条唤醒消息末尾挂上 `（@我/提到我/提问）` 标签，展平的 `@` 还会带 `@昵称(QQ:123456)`。

**后果**：旧版 `pickLatestText` 在真实对话里拿到的永远是 `【当前时间】`、插件状态尾巴或 `【心里偶尔浮起来的小事】`，由于必含数字或超长，`decide()` **几乎 100% 返回 `skip: false`（照常思考）**，整个插件在生产环境形同空转。

### 修复（`plugins/think-gate/lib/decide.js`）

- 新增 `extractWakeBlock(fullText)`：逆序扫描 `role === 'user'` 消息，用行首锚点 `/(?:^|\r?\n)【本次唤醒】[ \t]*\r?\n/` 精确定位独立成行的 `【本次唤醒】` 段落（避免误中 `【引导说明】` 里的同名文字，并自动跳过 `mind-wish` 单独 push 的尾部消息）；
- 新增 `cleanTriggerLine(rawLine)`：
  1. 剥除行首绝对/相对时间戳 `[10-27 16:20]`、`[+3m]` 与可选的 `#消息id`；
  2. 用负向先行断言剥除发言人前缀 `昵称(QQ:123456)：`（兼容昵称含冒号，且绝不误吞正文里的 `@机器人(QQ:xxx)`）；
  3. 剥除 `buildTriggerBlock` 在行尾附加的 `（@我/提到我/提问/拍我/引用…）` 标签；
  4. 剥除正文里的 `@昵称(QQ:123456)` 与 `[CQ:at,...]`，防止 QQ 号里的数字污染数字判据；同时完整保留 `[引用 …]`、`[图片]` 等方括号标记交由 `MEDIA_RE` 拦截；
- 兼容保留离线单测兜底路径（不含 `【本次唤醒】` 的裸消息照常解析）。

### 验证

新增 `plugins/think-gate/selftest.mjs`，覆盖 7 组真实场景（含完整 `buildUserPrompt` + 多插件尾巴 + `mind-wish` 独立消息 + 昵称含冒号 + 引用/提问/正文数字拦截 + 多行唤醒合并 + 旧版单测兼容），**7/7 全部通过**。

## 二、【高】核心补丁彻底告别“整文件覆盖”（`manifest.json` v2.2.9）

### 根因

v2.2.8 之前，`核心补丁/files/src/prompt.js`（基于 0.4.8.7）与 `src/reply-rescue.js` 采用 `kind: "copy"` 整文件覆盖。上游宿主升到 0.4.8.9 后，`prompt.js` 已前进 91 行（含 `pokeRules()` 等），继续整文件覆盖会直接抹掉宿主的新功能。

### 做法

1. **拆解 `src/reply-rescue.js` 为 5 项手术式补丁**（4 项 `anchor-insert` + 1 项 `replace-line`）：
   - `snippets/rescue-leak-pattern.insert.js`：在 `/sk-[A-Za-z0-9]{16,}/` **之前**插入工具调用残骸正则（自带尾逗号，无需担心上游末项有无逗号）；
   - `snippets/rescue-loose-send.insert.js`：在 `builtinLooseSend` 内拦截工具调用残骸；
   - `snippets/rescue-outbound-guards.insert.js`：在 `rescueUnsentReply` 之前插入 `registerOutboundGuard` 与 `runOutboundGuards`（含 BUG-01 空数组防御）；
   - `snippets/rescue-run-guards.insert.js` + `replace-line`：接入出站守卫管道并将合成参数替换为 `{ messages: guarded }`。
2. **拆解 `src/prompt.js` 为 4 项手术式补丁**（3 项 `anchor-insert` + 1 项 `replace-line`）：
   - `snippets/prompt-bracket-rule.insert.js`：在 `securityRules` 第 7 条**之前**插入「方括号不是你的表达格式」规矩（自带尾逗号，语法绝对安全）；
   - `snippets/prompt-search-fn.insert.js`：在 `memoryRules()` 之前插入 `searchBeforeAsking()` 函数定义；
   - `replace-line` + `snippets/prompt-search-call.insert.js`：在 `systemPromptOverride` 分支和默认主分支各自接入 `searchBeforeAsking()`。
3. **移除整文件副本**：删除 `核心补丁/files/src/prompt.js` 与 `核心补丁/files/src/reply-rescue.js`。现在 `核心补丁/files/src/` 下只剩 3 个宿主原本不存在的纯新增模块（`half-life.js` / `memory-people.js` / `memory-audit.js`，均为 `copy-new`，存在即跳过）。
4. **新增跨平台补丁脚本 `核心补丁/apply-core-patch.mjs`**：支持在 Windows / Linux / macOS 下直接用 `node apply-core-patch.mjs --app-dir <路径>` 执行全部 18 项手术式补丁。
