## 一、silence-ping 1.6.0 修的是「她分不清谁在跟谁说话」

| 新能力 | 做什么 |
|---|---|
| `cleanMessageForPrompt()` | 剥掉 QQ 的 `[引用 某人: …]` 头（它会挤掉真实正文），只留「（回应「…」）」 |
| `groupRecentTurns()` | 对方连发几条短句，归并成**一轮**，不再当成多条独立消息 |
| 双向身份标记 | 每条记录标 `【对方(昵称) → 对你说】` / `【你(bot) → 对ta说】`，消除「我/你」指代错位 |
| `buildSpeakerLedger()` | 发信前给「双方最后表态对账单」+ 归属锁定：禁止把已发过的话当成对方说的，也禁止重复追问 |
| 2-gram 防复读硬闸 | 候选文案与最近发言重叠 ≥0.75 判复读、重新生成（内存态，不写存档） |

### 兼容性（逐项核对过）

- **配置**：18 个设置键**零新增零删除**，默认值一个没变 → `dryRun / maxPerDay / cooldownMinutes` 等现值无缝继承；
- **存档**：同路径 `data/silence-ping.json`、同 `version:1`、**无版本闸无迁移**；新增 `lastState/lastTs` 为可选字段；`paused/pausedAt` 仍完整支持；
- **能力**：仍只调 `mind.wishes`（read/vent），与 mind-wish 的 provider 一致；
- **依赖**：仍只读 travel-whale 的会话存档，读不到降级为空；
- **发送通道**：与 1.5.2 相同（同一套 `send_private_msg`）。

> ⚠️ 覆盖后**重启宿主**才生效。
> 若在 1.5.x 上打过本地补丁（人称 / 引用头 / 轮次 / 对账单），1.6.0 **已全部内含**，旧补丁可丢弃。
