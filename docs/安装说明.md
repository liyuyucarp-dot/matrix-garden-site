# 安装说明

> 目标：把 17 个组件装进你的 QQ Agent（v3.1 口径），重启后她能自己过日子。
> 全程约 3 分钟。

---

## 〇、装之前

1. **备份你的 `QQ Agent\resources\app` 目录**（或者至少备份 `config.json`）
2. 确认程序**已关闭**（装核心补丁时尤其要关）
3. 确认你的 QQ Agent 版本支持 `plugins`（有 `resources\app\plugins` 目录就行）

---

## 一、一键安装（推荐）

在包目录里右键 `install.ps1` → **用 PowerShell 运行**。或者在 PowerShell 里：

```powershell
cd <这个包的目录>
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

脚本会：

1. 自动找 `QQ Agent\resources\app`（找不到会让你输路径）
2. 备份将被覆盖的文件到 `_backup_<时间戳>\`
3. 复制 `skills\*` 和 `plugins\*`
4. **问你要不要打核心补丁**（默认不打）
5. 打完后告诉你下一步要填什么

### 加参数静默装

```powershell
# 指定目录、连核心补丁一起打、不确认
powershell -ExecutionPolicy Bypass -File .\install.ps1 -AppDir "D:\QQAgent\resources\app" -WithCorePatch -Yes
```

| 参数 | 说明 |
|---|---|
| `-AppDir` | `...\resources\app` 的路径。不传就自动找 |
| `-WithCorePatch` | 同时打 9 个核心补丁（会先备份） |
| `-Yes` | 不再逐项确认 |
| `-DryRun` | 只看会动哪些文件，不真复制 |

## 三、装完之后：必做的五件事

### ① 填群号（**不填不会自动出门**）

打开设置 → 技能 → 矩阵庭院：

| 设置项 | 填什么 | 例子 |
|---|---|---|
| `homeChatKey` | **哪个群是"家"** | `group:123456789` |
| `cardTargets` | 明信片投给谁 | `group:123456789` 或 `private:10001,private:10002` |
| `travelGroups`（在 sleep-mood） | 哪些群同步旅行状态 | `123456789` |

> 这三个值我在打包时**清空了**（那是原作者的私人群号）。
> 格式：群直接写数字或 `group:数字`；私聊写 `private:QQ号`。

### ② 关掉 `silence-ping` 的演练模式

它默认 `dryRun = true`：**只判断、不真发**。想让她真的主动私信，到插件设置里关掉「演练模式」。

### ③ 确认较新插件的开关

（v2 的 `courtyard-doctor`、`courtyard-map` 也是新的，同样看一眼。）

`mind-wish`、`think-gate`、`bili-whale` 这三个是**较新的**，某些版本的插件页会显示成关闭。逐个打开。

### ④ 重启程序

插件能热加载，**技能不能**，核心补丁更不能。**装完一定重启一次。**

### ⑤ 把鲸鱼少女的两张参考图放进 `refs`（想让她每次都长一个样就必做）

```
角色图\whale--pro.jpg  →  <QQ Agent>\data\skills\travel-whale\refs\whale--pro.jpg
角色图\whale--q.jpg    →  <QQ Agent>\data\skills\travel-whale\refs\whale--q.jpg
```

- 文件名**保持原样**：`--pro` 给标准比例 / 半写实 / 绘本 / 赛璐璐四条画风，`--q` 给 Q 版画风。
- **不拷也能玩**：`refs` 里没有对应图就静默跳过、退回纯文字生图 —— 只是长相会飘。
- ⚠️ **别拿另一比例的图顶替**（参考图很锁比例：拿 Q 版图去生正比，出来还是 Q 版）。
- 这两张与包内提示词是**同一套外观**（深蓝长发 + 鲸鱼鳍耳 + 深蓝女仆长裙）。
  要换成你自己的角色：**图和提示词必须一起换** —— 同时改 `skills\travel-whale\postcard.js`
  里的 `WHALE_TPL` / `WHALE_WEAR`，只换一头会让模型一半听文字、一半听图，外观会飘。

## 四、可选：把用 `fs` 的组件加进可信插件

（`mind-wish`、`silence-ping`、`sleep-mood`、`bili-whale`、`qqzone`、`qzone`、`courtyard-doctor`、`courtyard-map`、`autobiography`、`knowledge-base`、`learning-loop` 等——遇到「触碰了高危能力」拦截就把对应目录名追加进去）

`mind-wish` 会读本机文件（`fs`/`path`），宿主的「高危能力闸」可能拦它。表现是日志里：

```
❌ mind-wish：模块「mind-wish」触碰了高危能力 …… 请在 config.trustedPlugins 里加入它的目录名
```

放行办法（任选其一）：

- **UI**：设置 → 安全 / 插件 → 可信插件列表，加 `mind-wish`、`courtyard-doctor`、`courtyard-map`、`autobiography`、`knowledge-base`、`learning-loop`
- **接口**：
  ```
  POST http://127.0.0.1:<端口>/api/config
  { "trustedPlugins": [ …原有的…, "mind-wish", "silence-ping", "sleep-mood", "bili-whale", "qzone", "courtyard-doctor", "courtyard-map", "autobiography", "knowledge-base", "learning-loop" ] }
  ```
  然后 `POST /api/skills/reload`

> 注意是**追加**，不要只写一个 —— 那会把别的可信插件一起清掉。

## 六、排障

### 组件加载失败

看日志里那一行 `❌ <名字>：<原因>`：

| 现象 | 原因 | 解法 |
|---|---|---|
| `category 非法` | 插件包的 category 写了枚举外的值 | 打开该插件的 `plugin.json`，`category` 改成 `utility` |
| `触碰了高危能力` | 插件 import 了 `fs`/`path` | 见上面第四节 |
| `入口文件不存在` | 复制时漏了 `index.js` | 重新复制整个目录，别只复制一部分 |

### 她不会自动出门

1. `homeChatKey` 填了吗（**最常见**）
2. 群里有口粮吗（商店买）
3. 是不是在夜里（默认 2:00–7:00 不走）
4. **新机制**：到点之后她会先"问自己一句"再决定。日志里会有
   `到点了但她说不想走（…）⇒ 下次 X 点再问` —— **这是正常的，不是坏了**

### 念想一直是空的

1. `mind-wish` 开了吗
2. 等够 10 分钟（吸收是低频的）
3. 有没有素材：`mood.json` 存在吗、`bili-whale` 有记录吗、庭院里这两天动过吗
4. 打开它的 `verbose`，看日志里有没有"新增/淘汰"

### 空间日记没写

1. `qzone` 装了吗、两个开关都开了吗 —— v2.3.0 起**社交线与日记线在同一个技能里**，
   设置里分别有「社交线」「日记线」开关（默认都开，总开关 `enabled` 默认关）
2. 到点了吗（默认 23:00）；也可以手动叫它写
3. 看日志里 `自动日记闸已启动（…到点 23:00…）`

### 主动私信一条都不发

1. `dryRun` 关了吗
2. 有白名单里的私聊吗（它只对有过对话的私聊生效）
3. 看日志里 `主动私信已发出（http）→ private:xxx` 有没有出现

## 七、回滚

装核心补丁的会备份到 `_backup_<时间戳>\`，把里面的文件复制回去就行。

**没备份也能回滚**：删掉对应的 `skills\` / `plugins\` 子目录即可（组件之间没有文件级耦合）。

## 八、升级注意

宿主程序升级后：

- **技能和插件**：通常还在，但新版本可能改了 API ⇒ 看日志有没有加载失败
- **核心补丁**：**一定会被覆盖** ⇒ 升级后要重打
