# 世界包与角色包（可插拔）

> 从 `travel-whale 4.6.0` 起，「她去哪儿旅行」和「谁陪她去」都不再写死在代码里。
> 这篇讲三件事：**怎么换主世界**、**怎么让任意世界变成主世界**、**怎么换旅伴**。
> 代码位置：`components/skills/travel-whale/core/theme-pack.js`（564 行）、`themes/<id>/theme.json`、`persona/companions.json`

---

## 一、一句话原理

原来「现实世界」= 写死的地球九大区。现在它叫**基础世界（base world）**，是一个**可替换的锚点**：

```
基础世界  ←  themes/<themeId>/theme.json   （显式主题包）
          ←  或 regions.json 里任意异世界  （一键晋升，无需写文件）
```

换锚点之后，下面这些东西**整套自动跟着换**（不需要你逐个改）：

| 跟着变的 | 说明 |
|---|---|
| 主地图 | 分区顺序、分区坐标（1000×470）、点阵大陆轮廓 |
| 默认解锁区 / 兜底区 | 新存档一进来就能去的区域 |
| 世界速写（worldbooks） | 每个区域的世界观文本 |
| 世界阶段（worldPhases） | 7 天轮换的内容 |
| 视觉速写 / 影调 | 明信片配图的风格与色调 |
| 属地事件标签 | 城市级/走廊级事件命中 |
| 原地球九大区 | 三种去处，见第四节 |

---

## 二、怎么换（最常用）

两个设置项，在 **设置 → 技能 → 矩阵庭院** 里填：

| 设置项 | 默认 | 填什么 |
|---|---|---|
| `worldTheme` | `default` | `default`/留空 = 地球九大区；`azeroth`（或「艾泽拉斯」）= 内置魔兽主题包；也可填任意世界，见第三节 |
| `earthInCustomTheme` | `otherworld` | 换掉地球之后，原地球怎么处理：`otherworld` / `hide` / `keep`（见第四节） |

> 改完**重启**最稳。运行时也支持热切换（`setWorldTheme()` 会立刻清全链路缓存），
> 但设置面板改的是配置文件，宿主读配置有缓存，重启更省事。

**内置两个主题包**：

| id | 名称 | 内容 |
|---|---|---|
| `default` | 现实世界（地球） | 亚洲/欧洲/北美…九大区，15 个异世界可穿越 |
| `azeroth` | 艾泽拉斯纪元 | 东部王国 / 卡利姆多 / 诺森德 / 潘达利亚 / 外域 五大洲作为主地图，点阵大陆、影调、世界速写全部内置（13 KB 的 theme.json） |

---

## 三、任意世界「一键晋升」为主世界

**不用写 theme.json**。只要那个世界已经在 `data/regions.json` 里（内置的 15 个异世界都算），
把 `worldTheme` 填它的 **id 或中文名**即可：

```
worldTheme = teyvat        （或「提瓦特」）
worldTheme = middleearth   （或「中土」）
worldTheme = 交界地
worldTheme = azeroth       （或「艾泽拉斯」）
```

引擎会做这些事（`buildProceduralMapForRegions()`）：

1. 把该世界的**子区域晋升为基础世界大区**（`baseWorld: true`）；
2. 自动生成 **1000×470 的主地图分区坐标**（没有手写坐标也能排布）；
3. 自动生成**点阵大陆轮廓**（`worldLand`），让 courtyard-map 立刻能画出完整大陆；
4. 世界速写 / 视觉速写 / 影调从该世界已有的 `azeroth|某某` 这类键**自动继承**（不必重写一遍）。

> 中文名匹配是模糊的：`theme.json` 的 `name`、`regions.json` 的 `name`、`baseWorldId` 三者都会试。

---

## 四、换掉地球之后，原地球去哪儿

`earthInCustomTheme` 三选一：

| 值 | 效果 | 适合 |
|---|---|---|
| `otherworld`（默认） | 原九大区**收束成一个异世界「蔚蓝地球」**，可穿越发现、买「蔚蓝星图」解锁 | 想保留"现实世界"作为旅途的一部分 |
| `hide` | 完全隐藏地球 | 纯奇幻设定，不想看到现实城市 |
| `keep` | 保留原 9 个地球大区，各自作为独立异世界 | 想两边都去 |

## 五、自己写一个主题包（进阶）

在 `<组件目录>/themes/<你的id>/theme.json` 放一个 JSON 就行：

```json
{
  "id": "myworld",
  "name": "我的世界（中文名也用作匹配）",
  "description": "一句话说明这个锚点做了什么",
  "baseWorldId": "myworld",
  "defaultRegionId": "myworld_capital",
  "earthMode": "otherworld",
  "home": { "name": "庭院", "gateLabel": "水镜之门", "homePlaceLabel": "庭院" },
  "baseRegions": [
    {
      "id": "myworld_capital", "parentWorldId": "myworld", "name": "王都",
      "kind": "fictional", "fictional": true,
      "baseWorld": true, "defaultUnlocked": true,
      "searchPrefix": "搜索用的前缀", "styles": ["奇幻插画"]
    }
  ],
  "map": {
    "gateLabel": "水镜之门", "homePlaceLabel": "庭院",
    "zoneOrder": ["myworld_capital"],
    "zones": { "myworld_capital": { "x": 0.5, "y": 0.5, "w": 0.4, "h": 0.4 } },
    "worldLand": [ /* 点阵大陆：可省略，省略则自动生成 */ ]
  }
}
```

**最小可用版**只需要 `id` + `name` + `baseRegions`（每项至少 `id`/`name`/`baseWorld`/`defaultUnlocked`）。
`map` 可以整段省略 —— 引擎会给没写坐标的分区自动排布。

改完用**自带的验收脚本**跑一遍：

```bash
node components/skills/travel-whale/theme-selftest.mjs
```

它做 4 组断言（180 行）：默认主题一致性、重锚定到 azeroth、世界速写/视觉/影调继承、快照 `mapTheme`。
你换了主题之后跑，能立刻看出是"哪一项没接上"。

## 六、角色包（换旅伴）

旅伴不再是代码里的常量，而是 `persona/companions.json`（3.9 KB，7 位）：

```json
{
  "fox": {
    "id": "fox",
    "name": "黑发兽耳小狐狸",
    "emoji": "🦊",
    "aliases": ["小狐狸", "狐狸", "GLM", "智谱"],
    "price": 4000,
    "foodCostMult": 2, "cardMult": 1.5, "rareMult": 2,
    "trait": "免费鸡蛋",
    "dailyTokens": 500,
    ...
  }
}
```

**换掉一位旅伴要同步改四处**（少一处就会显示不一致）：

| 位置 | 内容 |
|---|---|
| `persona/companions.json` | 名册本体：id / 名字 / 别名 / 能力倍数 / 特性 |
| `personas.json` | 人物卡（性格、说话习惯）—— 旅伴的"人设"在这 |
| `components/skills/courtyard-map/panel/portraits/<id>.webp` | 面板里的立绘（文件名必须等于 id） |
| `components/skills/courtyard-map/companions-lore.json` | 面板档案里的「来历 / 性格」两行 |

> 想**新增**一位旅伴：四处都加，再把 id 加进 `state.js` 的 `COMPANIONS` 表；
> 只想**改名**：至少改 `companions.json` 的 `name` 与 `aliases`（别名决定模型叫得对不对）。

---

## 七、⚠️ 切世界与存档

- **不用删存档**。地区表是按当前主题现算的（`loadThemedRegions()`），旧主题里存在、新主题里不存在的 id 会被过滤掉（代码注释原话："防脏数据把商店撑出幽灵条目"）。
- 新存档：`equipUnlocked` 会按当前主题的 `defaultUnlocked` 自动初始化（艾泽拉斯主题下 = 五大洲全解锁）。
- **老存档**：`equipUnlocked` 里是旧世界的 id。切换后如果商店或装备栏出现"点了没反应 / 地区不存在"，把它清空即可按新主题重算：
  ```
  data/skills/travel-whale/chats/<群>.json  →  "whale": { "equipUnlocked": [] }
  ```
- **切之前备份** `data/skills/travel-whale/chats/` 整个目录（一秒钟的事，出问题能退回）。

---

## 八、已知边界

- 只有 `regions.json` 里**已存在**的世界能被"一键晋升"；要全新世界，得先有地区数据（或写主题包）。
- `earthMode: keep` 时地球九大区与主题大区并存，商店条目会变多（预期行为）。
- 主题切换**不会**重画已生成的明信片/立绘（那些是图，不是数据）。
- 自动生成的 `worldLand` 是程序化点阵，精度不如手写坐标 —— 对地图外观有要求就手写 `map`。
