# 更新日志 · v2.0.0

## 一、新组件（2 个）

### 庭院体检 `skills\courtyard-doctor`（诊断工具，注册模型工具）

- 对模型开放 `courtyard_checkup`：一键体检矩阵庭院各组件——核心补丁是否在位、
  家/主人配置一致性、可信权限、禁言与风控链路、外部凭据存在性（只报"已配置/长度"，
  **任何 Key 的值一律不进输出**）、昨夜日记是否落盘
- 只读、不联网、不写文件；对机器人说「庭院体检」就出报告

### 庭院与旅程 `skills\courtyard-map`（可视化面板）

- 把庭院画进一张图：**她此刻在哪**（或在家做什么）、**随行旅伴**、**已解锁的旅行地**
  （真实世界 + 异世界，未到访的显示解锁装备提示）、**庭院近况时间线**、**明信片相册**（带图灯箱）
- 数据 30 秒快照自动刷新；对 travel-whale **零侵入**（只读它的存档与数据表）
- 旅伴**全量名册**：7 位全部显示，未解锁的标【未解锁】并禁入；emoji 严格对齐庭院本体
- 入口：设置 → 插件 → 庭院与旅程 → 「打开庭院与旅程」
  （若宿主主窗口做了顶层页签改造，顶栏「庭院」直达——该改造属宿主 UI，不在本包内）
- **依赖**：`skills\travel-whale`（只读）——本包已带，见下
