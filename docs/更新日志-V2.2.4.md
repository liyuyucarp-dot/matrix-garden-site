# 更新日志 · V2.2.4（2026-10-25）

> 只为**官方 0.4 适配**做的一次收尾：修一个两版共有的非法 `category`，并同步 bili-whale 的分类。
> 代码逻辑零改动。

---

## 一、`bili-whale` 的 `category` 非法

`plugins/bili-whale/plugin.json` 原本写的是 `"category": "fun"`。
而宿主（**官方 0.4 与 0.4.8.x 都一样**）的合法值只有：

```
model | message | knowledge | media | utility
```

非法值会被**静默回退成 `utility`**，并在每次启动时往日志里打一条：

```
[skill] ⚠️ bili-whale：category 非法（fun），已回退为 utility
```

这条警告在 0.4.8.x 上一直存在，只是没人往上看。已改为 `"media"`（B 站内容属于媒体）。

**影响**：0（功能不变，只是分类正确 + 警告消失）。

---

## 二、为什么这次单独发一版

因为同时在准备 **《矩阵庭院 · 官方 0.4 适配补丁 v1.0.0》**（独立小包，纯新增 6 项，见该包 README）。
适配工作里做了一次全量加载实测，顺带把这条警告揪出来了 —— 与其让两个包各带一份不一致的
`bili-whale/plugin.json`，不如正式包也跟着修掉。

---

## 三、官方 0.4 适配的结论（供参考）

用官方 0.4 自己的 `loadPlugins()` 实测：**27 个组件（11 官方 + 16 矩阵庭院）全部加载成功、0 失败、0 警告**。
需要的是 6 项**纯新增**补丁（3 个核心文件 + 3 处服务接线）；
`prompt.js` / `reply-rescue.js` **不需要覆盖**（官方 0.4 自带技能提示词段注入）。
已知降级：官方 0.4 的 UI 不认识 `settingsUi` / `panels`，定制面板不显示，但 `configSchema` 仍可配置。
详见适配包里的 README。
