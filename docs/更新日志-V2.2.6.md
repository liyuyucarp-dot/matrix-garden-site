## 二、「同行足迹」页（新页签）

按旅伴分组，列出**和谁去过哪个世界的哪座城、各几趟**（城市按最近一次出行排序，同城多次显示 `×N`）。
只统计**异世界**同行；现实城市不计入。没有记录时给一句"等她带上某位旅伴去异世界走一趟"。

---

## 三、两项新统计（travel-whale 4.4.6）

`state.whale` 新增两个字段（都是**增量**，不动任何既有字段）：

| 字段 | 形状 | 用途 |
|---|---|---|
| `compTrips` | `{ [旅伴id]: 累计趟数 }` | 档案里的「一共同行 N 趟」 |
| `mateCities` | `{ [旅伴id]: { "regionId|city": {regionId, city, country, n, firstAt, lastAt} } }` | 足迹页的城市 × 次数 |

### ⚠️ 与既有 `companionWorlds` 的口径区别（关键，别混）

| | `companionWorlds`（旧，技能门槛用） | `compTrips` / `mateCities`（新，面板用） |
|---|---|---|
| 记谁 | **只记带路的那位**（`trip.companion`） | **这一趟所有同行的人**（`trip.mates`） |
| 怎么计 | 按"去过几个**不同**异世界"**去重** | **按趟累加**（同一世界去两次算两趟） |
| 影响 | 决定旅伴技能能不能学 | 纯展示，**不影响任何解锁** |

所以技能解锁进度**没有变**，只是在档案里多了一栏"一共同行 N 趟"。

### 老存档

- 两个字段缺失时按 0 处理（`Number(...) || 0`），不会报错、不会清存档。
- **从重启后的下一趟异世界出行开始累计**；在此之前历史趟数无法补算（老存档里没有逐趟的同行名单）。

## 四、语气收敛（插件层）

按主人口径：**宿主不该替她决定"该用什么语气说话"**。

| 插件 | 之前 | 现在 |
|---|---|---|
| `sleep-mood` 心境段 | 每个心境 Tag 后面挂一句语气指令（"语气自然带点轻快" / "说话可以稍微嘴硬" / "带点揉眼睛"…） | **只报状态**：`【此刻心境】· 开心：中了两杯奶茶`，抬头改成"客观事实，不是说话要求，也不必据此改变语气" |
| `sleep-mood` 抬头 | `请将以下情境自然融入语气与动作` | `以下是客观事实，不是说话要求` |
| `sleep-mood` 陪闹句 | 附"语气带着困意和宠溺，别越聊越亢奋" | 只留"本来在睡觉、被叫醒、还剩几条" |
| `sleep-mood` 台词示例 | 把 `sleepLineExamples` / `wakeLineExamples` 拼进 system | **不再拼**（配置项保留不读，老配置不报错） |
| `mind-wish` 念想 | `【你此刻惦记的事】…（惦记了 3 天，想起过 5 次）` | `【心里偶尔浮起来的小事】…（前几天忽然想到过）`，去掉次数计数，尾巴改成"只是心里的余温，不是待办" |

> 元气/心境的**数值与因果**都保留（`元气 12/100（精力见底）｜原因：跑了长途`），只是不再附带"该怎么表现"。

## 五、升级注意

1. 覆盖 `skills/travel-whale`（4.4.6）与 `skills/courtyard-map`（1.1.0）后**重启宿主**；
   档案里的技能/足迹要等重启后的**第一份快照**才出现。
2. **面板先重开一次**：`map.html` 的 css/js 引用已加 `?v=20261026c`，
   若仍看到旧样式，说明 `map.html` 本身被缓存了 —— 重启宿主即可。
3. 立绘是静态文件，**删掉也不会崩**：`portraitOf()` 找不到图就回退 emoji 图标。
4. `compTrips` / `mateCities` 只增不改既有字段，**回退到旧版也不会报错**（旧版只是不读它们）。
